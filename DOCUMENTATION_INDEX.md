## 💡 Key Concepts Summary

### 1. ORM
```
Python Code → ORM → SQL → Database
```
Your project uses 10 different ORM query patterns.

### 2. CBV
```
One Class → Handles All CRUD → Less Code → More Features
```
Your project uses ListView, CreateView, UpdateView, DeleteView.

### 3. Pagination
```
100 Records → Divide by 5 → 20 Pages → Better UX
```
Your project: 5 records per page with navigation UI.

### 4. Search
```
User Input → Filter Query → Matching Results
```
Your project: Search by name OR email (case-insensitive).

### 5. Sorting
```
Records → order_by() → Sorted Output
```
Your project: Sort by name (A-Z or Z-A) or age (High-Low).

### 6. API
```
Frontend ↔ JSON API ↔ Backend ↔ Database
```
Your project: ViewSet + Router generates 6 REST endpoints automatically.

### 7. ViewSet
```
Multiple Views → One ViewSet → Less Code → Same Features
```
Your project: StudentViewSet replaces 6 function-based views.

### 8. Router
```
Manual URL Routing → DefaultRouter → Auto URL Generation
```
Your project: Router creates all CRUD URLs automatically.
